# Lesson 1 Workbook

## Exercise 1

Choose one ongoing AI project.

Create a one-page project briefing containing:

-   Objective
-   Current state
-   Constraints
-   Important decisions
-   Open questions

Use this briefing to start a brand-new conversation.

Record:

-   Did the AI stay focused?
-   Did it ask fewer clarification questions?
-   Was the output easier to use?

## Reflection

Compare this experience with continuing an existing long-running chat.
