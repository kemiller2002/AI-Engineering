# Lesson 1 Cheat Sheet

## Mental Model

Conversation = Temporary workspace

Artifacts = Long-term memory

## Rule

AI is stateless.

Your project should not be.

## Durable Artifacts

-   ADRs
-   Research summaries
-   Task contracts
-   Checklists
-   Tests
-   Repository maps

## Avoid

-   Treating chat history as the project database.
-   Depending on memory instead of documentation.
