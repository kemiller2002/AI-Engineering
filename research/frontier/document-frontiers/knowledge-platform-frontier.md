# Knowledge Platform — Document Frontier

**Origins:** `knowledge-platform/Repository-Architecture.md`; `Metadata-Standard.md`; `Search-Architecture.md`; `knowledge-genome.json`

## Knowledge and limitations

The platform specifies structure, metadata, search, and a graph-like knowledge genome. It lacks measured retrieval quality, maintenance cost, reference integrity, and agent navigation outcomes.

## Five highest-value opportunities

1. **RFR-009:** Enforce stable identifiers and references.
2. **RFR-010:** Compare graph-assisted work with file/search baselines.
3. **RFR-004:** Use representative retrieval/provenance tasks in the suite.
4. **RFR-006:** Account for curation and maintenance cost.
5. **RFR-005:** Test compiled context generated from platform metadata.

**Challenge:** Architecture precedes demonstrated demand. A minimal experiment should gate further graph or search implementation.
