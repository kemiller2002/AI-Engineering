# State-Constrained Architecture Research

This directory contains the reusable research program for state-constrained and
semantic-control architecture. It is independent of any one application.

## Authority and navigation

- `prompts/`: questions and missions posed to researchers. Prompts are not findings.
- `reports/`: evidence and analysis, including the complete numbered 01–12 series.
- `synthesis/01-12-semantic-control-architecture-research-synthesis.txt`: the
  cross-mission interpretation of the numbered series.
- `experiments/`: proposed benchmarks and experiment inputs. These are plans or
  fixtures, not completed empirical evidence unless a file explicitly says otherwise.
- `working-notes/`: exploratory and predecessor material retained for provenance.
  These files are historical context, not current architecture authority.
- `references/`: learning and background material.

Current generic implementation constraints derived from this work live under
`docs/architecture/semantic-control/`. Application-specific Time Entry inputs
live under `content/projects/time-entry/`.

## Numbered research series

The `prompts/` and `reports/` directories each contain missions 01 through 12
with matching numeric prefixes. The filenames distinguish every prompt from its
corresponding report. The synthesis is separate because it interprets the series
as a whole rather than recording one mission's evidence.

Research recommendations do not become implementation requirements merely by
appearing in a report. Consult the synthesis and current architecture documents
for the repository's present interpretation and intended implementation.
