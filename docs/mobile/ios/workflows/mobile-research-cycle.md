# Mobile Research Cycle

## 1. Capture

Run `Capture Research`. Save the question to `research/inbox/`.

## 2. Triage

In Working Copy, open the file and add why it matters, project, discipline, and priority. Commit related captures together or individually when they are consequential.

## 3. Prepare Context

Read `CURRENT-STATE.md`. Select only the relevant specifications, theories, evidence, and prior package. Avoid uploading the entire repository by default.

## 4. Execute

Use `ai-prompts/agents/Repository-Ready-Research-Agent.md` in ChatGPT. Require discrete files, a manifest, validation disclosure, a commit message, and an updated state.

## 5. Review

Save generated files into the Working Copy repository. Inspect the diff. Reject unsupported claims, accidental overwrites, and invented validation.

## 6. Commit

Commit accepted files with a focused message. Push to GitHub.

## 7. Continue

The next session begins from `CURRENT-STATE.md`, not from an assumption that ChatGPT remembers the prior conversation.
